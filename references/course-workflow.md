# 课件与课程状态

## 先解析，后确认交付

从本次指令、课件标题和课程目录定位课程。无论输入是文件夹路径还是直接上传，都先完成只读预解析。课程目录中已有“学习资料说明.md”和解析缓存时，先读索引并用缓存校验脚本比对原文件 SHA-256：缓存有效则用其定位章节与知识点，只重读本次相关页、需核实项和图片；缓存缺失或过期则读取原文，列出标题、页序、章节、知识点、图表、代码、公式及来源位置，并用旧缓存定位可能变化的部分。此阶段可读现有缓存，但不创建课程文件夹，不复制课件，不生成 Word，不写入或修订课程索引与缓存。

预解析完成后，一次性询问或确认未决项：

- 是否生成本课件的知识点解析；
- 是否同时新建或更新期末总复习；
- 需要哪一种或哪些目标语言，以及语言顺序；
- 直接上传且没有稳定课程目录时，是否新建文件夹保存课件副本、课程索引和生成文件，以及文件夹的名称与位置；
- 存在多个合理课程候选或教学位置不明时，确认所属课程与顺序。

本次指令已明确回答的项目不重复询问。得到答案后才进入生成阶段：直接上传时按用户选择创建课程文件夹或确定其他输出位置；文件已位于课程文件夹时，默认沿用其现有子目录与命名方式。保留原课件，不改写其内容。

每门课程使用自己的资料目录与“学习资料说明.md”，不把其他课程的来源、术语或复习文件并入。生成阶段若没有索引，从已解析材料建立最小索引：课程名、目标语言、已确认教学顺序、课件路径及 SHA-256、当前缓存路径、单课件解析路径、总复习路径、待同步项和术语表。用户确认交付后，对新解析或已变更的课件在课程目录的“解析缓存”子目录写入紧凑缓存，然后更新索引；用户拒绝稳定目录时不落盘缓存。复用已有索引格式，避免另造数据库。缓存格式、鲜度校验和回查规则见“分层课程缓存”。

对新文件先计算 SHA-256，并与索引和缓存中同一课件的版本比对。内容相同则沿用缓存定位已核对资料，不重复全文读取或生成；内容变化则根据旧缓存的页面或单元映射定位差异，回读原文并只修订受影响的知识点。先在同一课程目录生成并核查新解析与新缓存；核查通过后，把旧解析移入该课程的“历史版本”目录，缓存按来源短哈希保留历史版本，再更新当前索引指向。新解析未通过核查时保留当前文件与当前缓存指向。交付时列出变更的知识点、旧新来源和总复习待同步项。移动前核实源与目标路径属于该课程资料目录。

## 按需读取原课件

先列标题、页序、章节和可能含图表、公式、代码的页面，再读取与本次任务相关的正文。PDF 用 PDF 读取能力定位实际页；PPTX 用 Presentations 读取幻灯片及必要的讲者备注；DOCX 用 Documents 读取标题与段落。课件图片包含文字或关键关系时，多模态模型直接查看相关页面或图片并结合该页标题、正文与前后页解析；不能直接看图的模型导出相关图片后运行 OCR，再将识别文字放回课件上下文中解释，不把 OCR 输出直接当作最终知识点。PPTX 记幻灯片号；DOCX 记章节标题与段落位置，只有能稳定核实时才标页码。对仍未能可靠还原的图形关系写“图意待确认”，保留原位置。

## 全源覆盖门禁

PDF 和 PPTX 在生成前必须建立逐页覆盖清单。先从读取器取得实际总页数或总幻灯片数，再把从 1 到末页的每个单元恰好归入一种状态：`parsed` 表示已解析并映射到知识点，`excluded` 表示封面、纯装饰、重复页等经检查后明确排除，`unresolved` 表示已查看但暂时无法可靠还原。每个范围都写简短说明；`excluded` 必须写排除理由，`unresolved` 必须在输出资料中形成带来源位置的“图意待确认”条目。

文本提取为空不代表空白页，也不代表课件结束。此类页必须直接查看页面图像；非多模态模型改用可靠 OCR。OCR 不可用或识别不可靠时归为 `unresolved`，不得把后续页静默省略。不得只用“最大引用页码”代替逐页覆盖检查。

把覆盖清单保存为临时 JSON，并运行：

    node "<skill目录>/scripts/validate-source-coverage.mjs" --total <实际总页数或幻灯片数> --coverage <覆盖清单.json>

只有校验结果为 `complete: true` 才能生成或修订单课件解析、把缓存标为当前版本，或同步期末总复习；缺页、越界、重叠、无效状态和缺少说明都禁止生成。`unresolved` 属于已明确登记的覆盖状态，但交付时还必须核对对应的待确认条目确实出现在单课件资料和本次同步的总复习中。DOCX 没有稳定页序时，按标题和段落范围建立同样的完整单元清单并人工核对。

知识点按课件教学顺序组织。每个章节标题与知识点标题都写主要原文语言和用户目标语言译名；专有名词无通行译名时，用目标语言简短说明其含义。每项记录来源定位、课件明确内容和目标语言对照，解析后原则上加一个贴近日常、可具体想象的简短例子。例子默认只用用户选定的目标语言；课件原例翻译或改写后保留来源，自行构造时用目标语言标明“补充说明”。仅当用户明确要求双语例子时才同时保留原文语言。公式、图表、比较、实验步骤和代码按内容需要加入。代码、公式、变量、专有名词及符号按原材料核对，并将独立代码和公式排成醒目的专用块。模型依据课件上下文自行判断使用段落版还是表格版，不额外询问版式；课件包含成组的比较、框架、角色、阶段、指标或考试问答时选表格版，以连续解释、代码、公式或推导为主时选段落版。表格内所有表达课件知识的单元格也必须先写课件原文，再写目标语言对照，两种语言相同时只写一次。长篇解释和通俗例子仍放在表格外，不把全部内容机械表格化。

## 语言、术语与复习

每个知识点的标题与解释都以其主要原文语言先写，再用用户目标语言写；两者相同只写一次。通俗例子使用用户目标语言，不自动复制原文语言例子。混合语言课件逐知识点判断。术语表至少记录原词、源语言、目标语言、用户确认译法和来源；用户更改译法时，新输出采用新译法，在索引列出可能需要同步的旧文件。本次未要求修订的旧文件保持原样。切换目标语言时依据原课件和已核对的事实重新表达，避免在旧译文上继续翻译。

新课件默认只生成自己的解析 Word。只有本次明确要求更新期末复习，且该课件的全源覆盖校验通过时，才以已确认单课件解析为合并基础，回查原课件，按教学顺序增量更新。总复习必须同步该课件的全部新增知识点和带来源的待确认条目，不能只复制校验前已有的部分。后续课件补充早先知识点时，在旧知识点位置注明新来源，同时保留新章节内容。未更新或覆盖未通过的总复习在索引中记录待同步项和原因。

## 交付核查

逐项核对课件目录、逐页覆盖清单、知识点、来源定位、译文对应、公式、图表及代码。把读取器报告的实际总单元数与覆盖校验结果对照，确认没有静默缺页；再确认历史版本可回查、术语表与新文档一致、总复习完整同步本次课件的变更，并附上尚待确认的图意或资料缺口。
