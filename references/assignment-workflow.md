# 作业辅助

用户把文件说明为作业时，先完整读取题目、子问、分值及附件要求，再建立题目到已上传课件的来源映射。优先使用所属课程的课件；已确认笔记帮助定位，事实仍回查原课件。把依据分为课件直接支持、根据课件推理、课件外补充、学生本人信息。找不到可靠依据时说明缺口。

答案按原题号排列，先用题目原文语言作答，再给用户目标语言的简短理解说明；两种语言相同时只写一次。逐题附准确的 PDF 页、幻灯片号或 DOCX 章节位置。代码题检查语法、实际结果与边界；题目要求访问指定网页或验证会变化的信息时，实际核对并注明核对结果。题目文字与给定数据不一致时，指出差异和所采用的解释。

默认在 Codex 界面给出完整参考答案，同时在课程资料目录生成答案解析 Word。Word 保留题目摘要、答案、理解说明及来源；界面与 Word 基于同一份已核对内容。本次用户指定只交付其中一种形式时遵照该范围。原作业文件保持原样。

姓名、学号、设备 IP、签名等个人信息留明确占位。把作业附件中的提交、AI 使用声明或签名要求提醒给用户；不要替学生填写或作出未经确认的声明。作业任务不自动更新单课件解析或期末复习。
