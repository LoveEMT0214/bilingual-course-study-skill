# 表格版课程学习模板

## 适用范围

以 [表格版课程学习模板](../assets/course-study-table-template.docx) 为版式基线。它主要参考用户提供的考试复习 Word 中的表格系统，已移除原课程内容并保留中性占位。单课件知识点分析和期末总复习都可以使用；选择后必须从模板复制，不得从空白 DOCX 模仿。

模型在解析课件上下文后自行判断是否采用表格版，不把“是否使用表格”作为必问项。优先用于需要快速扫描或横向比较的内容：概念与定义、对象对比、阶段与结果、角色与职责、指标与判断方式、问题与答题核心、复习层次与题型。连续解释、通俗例子、长引用、公式推导和代码默认放在表格外；只有它们确实属于重复字段或比较矩阵时才进入表格。用户明确指定版式时优先遵从。

## 准备文档

在用户确认生成范围、语言和保存位置后运行：

    node "<skill目录>/scripts/prepare-notes-docx.mjs" --layout table --output <新文档绝对路径>

脚本拒绝覆盖已有目标。复制完成后替换所有占位文字，按需要克隆或删除表格组件。不得残留模板说明、方括号占位或参考课程内容。

## 两种使用方式

单课件知识点分析：标题已经写明课件名时，删除可选的“课件名称 / Course File” Heading 1；以 Heading 2 组织 Chapter，以 Heading 3 组织知识点。

期末总复习：每份课件保留一个 Heading 1 并默认另起一页；课件内部以 Heading 2 组织 Chapter，以 Heading 3 组织知识点。沿用文档模板规定的 18/16/12 磅标题层级和章节间距。

## 表格视觉规则

- 表头使用深蓝 `#17365D`、白色 9 磅粗体、水平及垂直居中。
- 正文行在白色与浅蓝 `#EEF4FA` 之间交替；正文为 8.5–9 磅，保持舒适换行。
- 外框及内部边框统一为浅灰 `#D9D9D9`、0.75 磅。
- 单元格上下约 5–5.75 磅、左右约 5.75 磅内边距；不得使用会截断文字的固定行高。
- 第一列是短标签时可加粗居中；叙述列左对齐。列宽按内容分配，不默认平均分列。
- 两列表适合“条目—解释”或“题目—答题核心”；三列表适合比较、阶段、证据或“维度—对象 A—对象 B”。
- 跨页表格必须重复表头，并避免只把表头留在上一页；一个知识点标题应与其说明或表格至少第一行保持同页。

## 内容与来源

表格只是表达结构，不改变知识点语言与来源规则。标题仍写原文与目标语言译名，表格中的知识内容也必须提供课件原文与用户目标语言对照；不能因为使用表格而省略翻译。两种语言不同时，每个相关单元格按“课件原文在上、目标语言在下”排列并使用明确标签。概念、维度、阶段和对象名称也采用“原文 · 目标语言译名”或上下两行。两种语言相同时只写一次，并删除空的目标语言标签。

两列表可在解释列中纵向排列原文和译文；三列比较表必须在每个对象内容单元格内纵向排列双语内容，不要为了双语扩展成五列窄表。表头、纯导航标签以及模型自行归纳的题型提示可只用目标语言，但凡直接表达课件知识、定义、关系、步骤或判断依据的单元格都必须双语对应。表格中的事实仍要能回查到页码或幻灯片号。课件外补充在对应单元格中用目标语言标“补充说明”。通俗例子默认使用用户目标语言，并优先放在表格后的普通段落，避免长例子挤压列宽。

同一组表格保持相同表头颜色、边框、字体、行底色和对齐方式。不要把整份文档全部表格化；当内容不能形成稳定字段或可比较记录时，回到普通段落、列表、Formula Block 或 Code Block。独立代码与公式必须放在表格外，使用浅灰底、蓝色左边线和清晰的块前后间距，除非它们只是非常短的对比字段。

## 交付检查

逐页渲染并确认：表头无孤行，跨页表头正确重复；文字没有裁切、重叠或贴边；列宽符合内容；交替底色连续；每个知识内容单元格都有课件原文与目标语言对照，同语言单元格没有重复或空标签；来源完整；标题层级正确；所有占位均已删除。任一项失败都不交付。
