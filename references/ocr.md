# 图片文字识别

当课件的关键文字位于图片、扫描页或嵌入图像中时，按模型能力分流：

- 多模态模型：直接查看相关页面或导出图片，识别可见文字、排版层级和图中关系，再结合该页标题、正文、前后页和课程术语解析知识点。不必为可直接看清的内容另行运行 OCR。
- 不能直接看图的模型：先用原格式的读取能力定位并导出相关图片，再运行 [OCR 辅助脚本](../scripts/ocr-image.mjs)。脚本面向 PNG/JPEG；其他格式先导出为 PNG。只处理与本次知识点有关的图片，不批量输出整份课件的图像文本。

示例（将 <skill目录> 换成此 skill 的实际绝对路径，可从任何工作目录运行）：

    node "<skill目录>/scripts/ocr-image.mjs" --input <绝对图片路径> --lang eng
    node "<skill目录>/scripts/ocr-image.mjs" --input <绝对图片路径> --lang chi_sim+jpn --cache-dir <课程目录内的缓存路径>

首次使用某语言时，脚本尝试从可信来源获取识别包并缓存。网络不可达时，先从可信包或已安装资源取得对应的 .traineddata，放入缓存目录或用 --lang-path 指向本地目录，再运行脚本。按当前环境的联网与文件权限执行。脚本只把识别文字和置信度输出为 JSON；原图、课件和作业文件不被修改。OCR 输出是中间证据，不是最终解析：模型必须结合图片位置、本页与前后页内容、课程术语和识别置信度进行详解与核对，尤其注意公式、符号、表格和代码。仍不能可靠表达图中关系时，标“图意待确认”，由用户补充或交给可看图模型核查。
